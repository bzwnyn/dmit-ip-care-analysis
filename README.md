## 先搞清楚：DMIT 的 IP Care+ 到底是什么

**IP Care+** 是 DMIT 针对 Premium（Pro）和 Eyeball（EB）产品线推出的一项增值服务，核心功能就一个：**缩短免费换 IP 的等待周期**。

默认情况下，Pro 和 EB 套餐的用户在 IP 被完全封禁后，可以每 15 天申请一次免费更换。这个周期对大多数人够用，但如果碰上那种频繁被墙的节点，15 天等一次确实有点慢。

买了 IP Care+ 之后，等待周期缩短到 **7 天换一次**。

还有一个附加权限：随时可以付 5 美元强制立即换，不受时间间隔限制。这条规则有没有 IP Care+ 都适用，但有了 IP Care+ 的话，你的"计划性免费更换"频率更高，5 美元紧急换的需求自然也会少一些。

几个细节值得单独说一下：

1. **免费换 IP 的条件是"IP 被完全封禁"**，不是"我感觉慢了"或"443 端口不通"。具体来说，ICMP 和 TCP 全部端口都必须被封，才符合免费换的条件。如果你的 IP 还有任何国家或端口能通，那就算不上"完全被封"，换的话要收费。

3. **剩余服务时间不足 7 天也不能免费换**。快到期了临时换 IP 的路子走不通。

4. **Tier 1 系列用的是 IP Guarantee+，不是 IP Care+**，这是两个不同的服务。

## IP Guarantee+ 是什么？和 IP Care+ 有什么区别

说清楚 IP Care+ 就绕不开另一个服务：**IP Guarantee+**，主要针对 Tier 1 系列套餐。

Tier 1 是 DMIT 的国际线路，没有专门的中国方向优化，所以分配到的 IP 不保证在国内能用。

- **月付 T1 套餐**：DMIT 不保证分配的 IP 国内可达。如果想规避这个风险，可以在购买时额外付 **$1** 开通 IP Guarantee+，开通后如果 IP 在敏感地区不可用，可以提工单免费换一个能用的。
- **非月付 T1 套餐（季付、半年付、年付）**：IP Guarantee+ 已经包含在套餐里，不用额外花钱。

所以结论是：买 T1 套餐，如果是月付，建议多花这 1 美元；如果是季付及以上，直接白送，不用操心。

## 什么情况下值得买 IP Care+？

说实话，大多数人不需要买。

Pro 和 EB 套餐默认就有 15 天一次的免费换 IP，换一次之后运气好的话新 IP 能用很久。被墙这件事概率本身不算高，除非你把这台 VPS 用在非常容易被识别的场景。

**这几种情况可以考虑买**：

- 用的节点所在 IP 段历史上被墙记录比较多，自己研究过的
- 业务对连通性要求高，断了就损失钱的
- 想要 7 天换一次的弹性，而不是等满 15 天
- 过去几个月已经遇到过 2 次以上 IP 被封的

**这几种情况不用买**：

- 刚买第一台 DMIT，不知道自己节点 IP 段质量怎么样
- 只是偶尔用用，连通性要求不高
- 选的是 Pro 或 EB 套餐，IP 段质量通常比 T1 好一些，被墙频率相对低

说白了，IP Care+ 是为那种"已经被墙过、知道自己需要更高频率换 IP"的用户准备的，不是标配。

## 怎么判断 IP 是不是真的被封了？

很多人一遇到连不上就以为 IP 被封，其实不一定。

快速判断的思路：

1. **换个网络环境**：用手机流量代替宽带试一下，如果都连不上才可能是 IP 问题，而不是本地网络问题
2. **用 IP 检测工具**：在线输入 VPS 的 IP 和端口，看国内/国外各自的连通情况。"TCP 可用"说明能正常连接，"ICMP 可用"说明能 ping 通
3. **核对封禁程度**：DMIT 的免费换 IP 条件是 ICMP 和 TCP 全部端口都被封。如果只有部分端口不通，换 IP 就要付费

顺便一提：一台 VPS 从开通到第一次 IP 被封，这段时间因人而异。有的人几个月都相安无事，有的人可能开通一周就碰上了——和 IP 段本身的历史使用情况有关，和 DMIT 运营水平关系不大。

## 申请换 IP 的流程

很简单，三步：

1. **确认 IP 确实被完全封禁**（ICMP + TCP 全端口不通，且实例已购买超过 7 天，剩余时间超过 7 天）
2. **登录 DMIT 后台，提交工单（Ticket）**，说明需要更换 IP，并提供实例 ID
3. **等待客服处理**。一般响应速度挺快，不用等很久

如果是付费立即换（$5），同样走工单流程，DMIT 核实后会帮你操作。整个过程不需要自己动手改配置，换完后登录的 IP 就更新了。

## IP 地址的几个常见问题

**Q：季付或年付 T1 套餐自带的 IP Guarantee+ 是什么意思，实际用起来有什么区别？**

对月付 T1 用户来说，新开机器分配到的 IP 可能在国内根本访问不了，这是 Tier 1 线路的特性——不保证国内连通。IP Guarantee+ 就是"如果你不幸分到了一个国内用不了的 IP，可以提工单免费换一个能用的"。季付及以上套餐自带这个保障，月付用户需要额外花 $1 购买。

**Q：能不能同一台机器上有多个 IP？**

绝大多数套餐不支持。目前只有洛杉矶 Pro 系列（LAX Pro）的部分套餐可以申请添加额外 IP，具体要提工单咨询。

**Q：我的 IP 换了之后还被墙怎么办？**

只能继续等 7 天（有 IP Care+）或 15 天（无 IP Care+）再换。如果等不了，花 $5 可以提前换。没有"无限换"的选项，这点要有预期。

**Q：DMIT 的退款政策怎么样？**

购买 3 天内且流量使用不超过 30GB，可以全额退款（会扣支付网关手续费）。购买超过 3 天但不超过 30 天，可以按剩余服务时间部分退款。退款可以原路返回账户余额（免手续费）或退回支付方式（可能有手续费）。

**Q：DMIT 支持哪些付款方式？**

支持支付宝、微信支付、PayPal 和信用卡，对国内用户来说付款比较方便，不需要绑国际卡。
